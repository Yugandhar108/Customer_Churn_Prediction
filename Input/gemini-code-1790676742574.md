## Phase 4: Model Building (Task C)

### General Preprocessing & Setup
1. Encode binary and categorical targets (`Churn` -> `0`/`1`).
2. Perform train-test split (`train_test_split`) with standard proportions (e.g., 80/20 or 70/30).

---

### Model 1: Single Feature Baseline (`tenure`)

* **Feature:** `tenure` | **Target:** `Churn`
* **Architecture:**
  * Input layer: 12 nodes, `ReLU` activation.
  * 1 Hidden layer: 8 nodes, `ReLU` activation.
  * Output layer: 1 node, `Sigmoid` activation.
* **Optimization & Training:**
  * Optimizer: `Adam`
  * Loss Function: `binary_crossentropy`
  * Epochs: 150
* **Evaluation:**
  * Predict on test set & generate a Confusion Matrix.
  * Plot the **Accuracy vs Epochs** graph.

---

### Model 2: Single Feature with Dropout Layers

* **Feature:** `tenure` | **Target:** `Churn`
* **Architecture:**
  * Input layer: 12 nodes, `ReLU` activation.
  * Dropout layer: Rate = `0.3`.
  * 1 Hidden layer: 8 nodes, `ReLU` activation.
  * Dropout layer: Rate = `0.2`.
  * Output layer: 1 node, `Sigmoid` activation.
* **Optimization & Training:**
  * Optimizer: `Adam`, Epochs: 150.
* **Evaluation:**
  * Predict on test set & build Confusion Matrix.
  * Plot the **Accuracy vs Epochs** graph.

---

### Model 3: Multi-Feature Model

* **Features:** `tenure`, `MonthlyCharges`, `TotalCharges` | **Target:** `Churn`
* **Architecture:**
  * Input layer: 12 nodes, `ReLU` activation.
  * 1 Hidden layer: 8 nodes, `ReLU` activation.
  * Output layer: 1 node, `Sigmoid` activation.
* **Optimization & Training:**
  * Optimizer: `Adam`
  * Epochs: 150
* **Evaluation:**
  * Predict on test set & generate Confusion Matrix.
  * Plot the **Accuracy vs Epochs** graph.
